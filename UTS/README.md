# UTS Pengolahan Citra - Konversi Grayscale, Biner, dan Terindeks

## 📌 Deskripsi Proyek
Proyek ini merupakan tugas Ujian Tengah Semester (UTS) dari mata kuliah **Pengolahan Citra**.
Program ini dapat melakukan 3 jenis konversi citra:
- Grayscale | Erwin 
- Biner (thresholding) | Yoga 
- Terindeks (indexed color) | Mahesa
