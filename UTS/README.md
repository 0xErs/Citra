# UTS Pengolahan Citra - Konversi Grayscale, Biner, dan Terindeks

## 📌 Deskripsi Proyek
Proyek ini merupakan tugas Ujian Tengah Semester (UTS) dari mata kuliah **Pengolahan Citra Digital**.
Program ini dapat melakukan 3 jenis konversi citra:
- Grayscale
- Biner (thresholding)
- Terindeks (indexed color)
